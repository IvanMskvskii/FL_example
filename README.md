# FL_example
Симуляция федеративного обучения.

В рамках решения задачи было проведено федеративное обучение для 5 клиентов, агрегация весов и сравнение итоговой модели с централизованной на отложенной выборке. 
Обе модели имеют одинаковую архитектуру. 

В качестве данных использовался датасет APTOS 2019, содержащий снимки глаз пациентов (https://www.kaggle.com/competitions/aptos2019-blindness-detection/data). Задача - оценка степени тяжести диабетической ретинопатии по шкале от 0 до 4:
0 - Отсутствие диабетической ретинопатии;
1 - Легкая;
2 - Умеренная;
3 - Тяжелая;
4 - Пролиферативная диабетическая ретинопатия.

Для федеративного обучения использовались библиотеки PyTorch и Flower.

В результате федеративное и централизованное обучение прошли успешно. Централизованная модель показала более высокое качество accuracy, чем федеративная (0.7108 и 0.4925 соответственно), что может быть связано с тем, что федеративная модель обучается в условиях non-IID распределения данных, ограниченного обмена параметрами и отсутствия глобальной аугментации.
